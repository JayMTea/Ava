  • Drives the apps you already run

    Point Ava at an app and it becomes a tab: Ava watches it, charts it, acts in it. MCP tool servers plug in the same way, each one network-fenced.

  • You can see everything it does

    Watch it work: speed, cost and energy on screen. Changes Ava writes to its own code wait for your approval as git commits.

  • Personalized by you, not for you

    Ava ships with no personality. You write how it talks. It learns from your chats and files, and you can read, correct or delete any of it.
