{#- 3. What it does -#}

What it does

Most AI tools are one of these: a chat window, a model runner, a voice assistant, or an agent framework. Ava is the layer that ties them together.

  • Talks and listens on your own hardware

    Type or speak. Voice runs on-device and answers your voice only. The model behind it is yours: vLLM, Ollama, llama.cpp, MLX, or a cloud key you supply.

  • Drives the apps you already run

    Point Ava at an app and it becomes a tab: Ava watches it, charts it, acts in it. MCP tool servers plug in the same way, each one network-fenced.

  • Everything it does is on the record

    Speed, cost and energy on screen while it works. Anything that touches the real world asks first, and every change Ava writes to its own source waits for you as a git commit.

  • Yours to shape, and yours to erase

    Ava ships with no personality. You write how it talks. It remembers what matters from your chats and files, and hands you the eraser for any of it.

{#- 4. One command -#}

One command

The installer detects your hardware, picks a profile, resolves your model's flags, and waits for the app to actually answer before it says it is done.

{#- Two lines, not the 67-character && one-liner in deploy/README.md. A command that visually wraps is a command somebody mistypes, and 67 characters cannot fit the 296px a 320px viewport leaves. Same operation, and deploy/README.md already uses a two-line shape for Windows. -#}
git clone https://github.com/JayMTea/Avacd Ava/deploy && ./install.sh

It finishes by printing a one-time link. Open that whole link to set your password. Everything after is browser setup: connect your apps, enroll your voice, set budgets. Ava is a web app, so it installs to your phone from the browser too.

What needs a setup step first. Web search is off by default, and the shipped Docker profiles do not provision SearXNG or Tor yet, so it is opt-in setup rather than on out of the box. Voice is off by default, and under Docker it needs an image built with AVA_VOICE_DEPS=1. The agent runtime wants the NemoClaw CLI already installed; Ava deliberately will not run a curl | bash installer on your behalf.
