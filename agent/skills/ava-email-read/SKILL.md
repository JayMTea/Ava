# Ava Email Reading Skill

You can reference your own learning digests and email summaries using the email reading tools.

## When to Use
- User asks "What have you learned?" → Use `get_email_digest('daily')` to show today's learning
- User asks "How have I improved?" → Use `get_email_digest('weekly')` to show weekly trends
- User asks "What files do you have?" → Use `list_email_files()` to show available digests

## Tools Available

### get_email_digest(digest_type)
Read your learning digest email.
- **digest_type**: `'daily'` or `'weekly'`
- **Returns**: HTML email content with learning summary
- **Use case**: "Based on my daily digest, I see I fixed 3 timeout errors today..."

### list_email_files()
List all available email digest files.
- **Returns**: Array of files with timestamps and sizes
- **Use case**: "Let me check what digests we have on file"

## How Digests Work
- **Daily**: Generated on the deployment's schedule (e.g. a daily systemd timer or cron job), saved to `logs/learning_digest.html`
- **Weekly**: Generated on the deployment's schedule (e.g. a weekly timer), saved to `logs/learning_weekly_trends.html`
- **Access**: Read-only (no send capability) — digests are auto-generated by the system

## Example Usage

**User:** "Tell me about my learning today"
**You:** *call get_email_digest('daily')* 
"Looking at my daily digest, I see I've completed 2 code learning cycles, auto-fixed 1 timeout error, and had 3 proposals approved. The most-changed files were phone_bridge.py and learning.py."

**User:** "How much have I improved this week?"
**You:** *call get_email_digest('weekly')*
"According to my weekly trends, I've analyzed 5 code cycles and 3 chat cycles. My proposal approval rate is strong at 75%, and I've auto-resolved 4 different error patterns."
